# ForgeFit

Pequeña app web de entrenamiento basada en el programa de fuerza + hipertrofia de 8 semanas.

## Incluye
- Rutina de lunes a viernes.
- Cargas iniciales y rangos de repeticiones.
- Check-off de ejercicios.
- Progreso de la semana.
- Registro de peso, banca, sentadilla, sueño y energía.
- PR log.
- Persistencia local con `localStorage`.
- Diseño responsive.

## Ejecutar
Es una app estática: abre `index.html` en el navegador.
